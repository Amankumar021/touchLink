# TouchLink

A modular smartphone-based wireless computer control platform.

## Technology

- Mobile: HTML, CSS, JavaScript, Vite
- Backend: Node.js, Express, Socket.IO
- Desktop: Python 3.12
- Initial platform: Windows 11
- Initial transport: Wi-Fi

## Modules

- Smartphone touchpad
- Gesture engine
- Virtual keyboard
- Media controller
- Presentation mode
- Device pairing
- Security and authentication
